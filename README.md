# Receita de bolo pra rodar

- Cria uma pasta external na raiz
- cria uma pasta SDL3 na pasta external
  - include/SDL3/ inteiro
  - lib/SDL3.lib
- Cria uma pasta vulkan na pasta external
- Copia o Vulkan SDK pra a pasta external/vulkan
  - include/vk_video/
  - include/vulkan/
  - lib/vulkan-1.lib
- Roda `cmake --build build`

Agora aperta F5 e fé
